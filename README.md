# 💫 About Me:
I'm Sidney. I build web applications, onchain protocols, and AI-integrated tools.<br>My work sits at the intersection of full-stack web, onchain development, and AI-powered systems. I care about how things are built — not just that they work, but that they're built right. Clean architecture, clear decisions, and code that holds up under real conditions.<br>I take the craft seriously. Whether I'm working solo or as part of a team, the standard doesn't change.<br>Open to contracts and team roles. If you're working on something that requires genuine technical depth let's talk


# Areas of Work:

1. Full-stack web application development

2. Frontend engineering — component architecture, UI systems, responsive design

3. Backend engineering — REST APIs, server logic, database design and integration

4. Frontend + Web3 integration — wallet connect, smart contract interaction, onchain data display, verification UI, dashboards

5. AI-powered application development — Claude API, LLM integration, prompt engineering, AI-driven features

6. Payment integration — Flutterwave, Paystack

7. Technical writing and documentation 

8. Expanding continuously — this list is not the ceiling.


# **Currently Working On**



ExamChain — an AI-powered exam preparation platform built on Solana. Students can access study materials, take AI-generated practice sessions, and have their results verified onchain. Built with Next.js, the Claude API, Anchor, and IPFS.
